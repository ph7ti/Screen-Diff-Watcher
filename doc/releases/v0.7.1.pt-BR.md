# v0.7.1 — Repaginação da janela, som default empacotado e popup do som

Notas de release da versão **0.7.1** (patch: a janela foi repaginada num grid 2×2, o som default
passou a ser um `alert.mp3` empacotado e escolher um som abre um popup de ajuda). Veja também o
[`CHANGELOG.md`](../../CHANGELOG.md) e o design em
[`doc/00 §3.7/§11.2/§12.4`](../00-Documento_de_Arquitetura_e_Especificação.md).

## Adicionado

### Som default empacotado (`alert.mp3`)

O `file` padrão dos alertas `sound` agora é **`"alert.mp3"`**, e esse arquivo vai junto com o pacote em
`screen_watch/assets/sounds/` (declarado no `package-data` para o wheel e no `datas` do PyInstaller).
O resolver `platform/audio.py::resolve_sound_path` procura, para um `file` relativo:

1. `app_home()/sounds` (pasta do usuário — sempre vence);
2. `resources.bundled_sounds_dir()` (`screen_watch/assets/sounds`);
3. o CWD (comportamento legado).

Caminhos absolutos são usados como estão. Configs existentes com `alert.wav` (ou outro caminho)
**não mudam**; o default novo só vale para configs novas ou quando o usuário trocar a linha. Arquivo
ausente continua caindo no `beep()`.

### Popup ao escolher o som

Depois de cada **Escolher…**, a GUI abre um aviso modal explicando onde colar o trecho copiado:
aponta para o `config.yaml`, o perfil desejado (citando o **perfil ativo**) e o alerta
`type: "sound"`, com três botões — **Copiar caminho e abrir YAML** (padrão), **Só abrir o YAML** e
**Fechar** (`dialog.sound_*`, nos dois catálogos i18n).

### Repaginação da janela

O painel superior agora é um **grid 2×2** seguindo o mockup `UI.txt`:

- **(0,0) Seleções** — fileira Novo Target / Remover / Recarregar / **Ver local da seleção**, legenda,
  lista e a linha **Nome da seleção** + Renomear.
- **(0,1) Monitoramento** — grid de duas colunas: Iniciar/Idioma, Parar/Re-armar baseline, Modo/Perfil,
  Armar Ações/Desarmar Ações, Armar por…/Minimizar para o tray, mais **Gravar prints (evidências)** e o
  status de arming.
- **(1,0) Ações da sessão** — lista, contador e a fileira horizontal Nova ação…/Editar…/Remover
  Ação/Executar ação.
- **(1,1) Detecção e alertas** — primeiro o `text_watch`, depois o som (campo read-only com o snippet e
  Escolher…/Reproduzir/Copiar caminho).

O rodapé (`QSplitter`) é um grupo **Status** com Status/Último/Log, e a coluna direita tem
**Prints / Testar alerta… / Abrir YAML**.

## Mudado

- **Ver local** passou do Monitoramento para a fileira de botões das **Seleções**; **Gravar prints
  (evidências)** foi para o **Monitoramento**.
- Textos da GUI: **Ver local da seleção**, **Armar Ações** e **Desarmar Ações**.
- O campo do som exibe o trecho `file: "..."` direto (o rótulo de snippet separado foi removido);
  **Copiar caminho** e **Reproduzir** ficam desabilitados sem valor.

## Notas

- O som empacotado fica em `src/screen_watch/assets/sounds/alert.mp3` (cópia única versionada);
  `resources.py` ganhou `bundled_sounds_dir()`/`default_sound_path()`.
- Chaves i18n novas: `dialog.sound_title/sound_help/sound_copy_open/sound_open_only/sound_close` (nos
  dois catálogos). O `_copy_sound_snippet` agora monta o trecho a partir do arquivo escolhido/efetivo,
  em vez de ler o rótulo removido.
- **Nota de versionamento**: `0.7.0 → 0.7.1` é uma escolha consciente de **PATCH** (a regra SemVer
  documentada sugeriria MINOR — mas são mudanças de layout/UX e do default do som, sem quebra de API
  nem de dados).

## Atualizando

Nada a migrar. Configs existentes mantêm o `file` delas (ex.: `alert.wav`); para usar o som
empacotado, ponha o `file:` do alerta `sound` como `"alert.mp3"` (ou remova a linha para aceitar o
default).
